# 75 Hard - LeetCode Challenge 🔥

A personal challenge to solve **LeetCode problems every day for 75 days straight** — no skipping, no excuses. Inspired by the discipline of the "75 Hard" mindset, applied to sharpening Data Structures & Algorithms (DSA) skills.

## 🎯 Goal

- Solve at least **1 LeetCode problem daily** for 75 consecutive days
- Build consistency and strengthen problem-solving skills
- Track progress and revisit tricky problems for revision

## 🛠️ Languages

Solutions are written in **Python** and **C++**, depending on the problem or mood that day.

## 📁 Structure


## 📌 Rules

1. Solve at least one problem every day — no zero days.
2. Missing a day resets the streak to Day 1.
3. Every solution must be pushed to this repo the same day.

## 🚀 Why?

Consistency beats intensity. This challenge is about building a daily coding habit that compounds into strong DSA fundamentals over time.
